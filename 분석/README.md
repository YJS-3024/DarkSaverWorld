# 원작 분석 기준

현재 데이터 분석 기준은 사용자가 추가한 **후기 설치본 `saver/data1.cab`**이다. 정확한 배포 버전명은 미확정이므로 `Saver_Late`라는 자료 식별자를 사용한다.

- 최신 데이터·버전 차이·미확정 항목: [후기 버전 분석 기준](../설계/11_후기버전_분석기준.md)
- 후기 원문 변환·카탈로그: [Saver_Late](Saver_Late/README.md)
- 이전 설치본과 과거 바이너리 분석: `Saver_1.2/`, `닥세_리소스/분석결과/`의 버전 미표기 과거 자료. 변경 파일의 주소·수치·레코드 의미는 후기 버전에서 재확인하기 전까지 그대로 적용하지 않는다.

동일한 원본 파일은 이전 분석을 재사용한다. 변경된 파일은 후기 데이터가 우선한다. 원본 서버에서만 알 수 있는 판정과 사용자가 확정한 싱글판 정책은 데이터 갱신과 구분한다. Unity 적용·실행 검증 여부는 `설계/10_분석_적용_진행표.md`를 따른다.
