### 원격 후속 변경의 필수 회귀

- MP 정책은 최신 개발 기록 기준으로 **중단 저장은 관측 현재MP, 정상 전투 귀환은 출전 아군 최대MP 회복**이다. 마법 사용 후 주인공 중단MP40·정상 귀환MP45를 구분하고, 추가 출전 아군·사망 아군도 검사한다.09727602의 정상 귀환MP40은 과거 구현 관찰값이며 최종 기대값이 아니다.
- 실제 uGUI 버튼·입력·마스킹·탭/포커스·월드 입력 차단을 다시 검사한다. 이전 UI Toolkit 요소를 찾는 자동화는 새 UI 검증 증거로 재사용하지 않는다. Start 카메라·Game 뷰 표시도 확인한다.
- 동일 기기에서 여러 계정 가입→전환/로그아웃→각 계정10슬롯 생성/선택/저장/재접속을 검사한다. 루트 기존 계정/저장 보존, 신규 계정의 타 계정 상태 비상속, 대소문자 중복 거부, 타 계정 슬롯/종료 기록·형제 경로 접근 거부를 포함한다.
- 복원된 카오시아 지형·원형 배치에서 실제 훈련장/상점/신전/필드 출입구·복귀·NPC 거리·충돌·카메라를 다시 확인한다. 이전 좌표를 새 맵에 그대로 적용하지 않는다.
-03 저장 실패를 격리 사본에서 재현해 실패 단계·예외 종류·HResult 기록, 수동 ‘저장 다시 시도’와 정상 후속 연출을 검사한다. 재시도 전후 커서·RNG·아이템·개정 번호의 부분 게시/중복 적용이 없어야 한다. 경로·계정·예외 원문 노출 여부도 확인한다.

- 카오시아 무기/방어구/장신구/마법도구/은행/창고/신전 출입과 복귀, 실제 주인 클릭·가격/수량·은행/창고 입출고·능력치 반영을 확인한다.
- NPC 카오시아8·다른 세 마을 각6=26명. 거리 제한·중복 요청·대화 종료·입력 잠금 해제, 전직·고용·편성·의뢰·기록관 연결과 실제 확정을 구분한다.
- 제거된 시설 목록·HUD 바로가기·상점 주변 이용 버튼이 닫기/뒤로 가기 후 재등장하지 않는지 확인한다. UI 클릭의 월드 이동/공격 관통도 검사한다.
- 각 시나리오는 입장 조건→시작 연출→편성/좌표→진행/목표 타일→승패→종료 연출→보상/영입→복귀→저장/재접속을 한 단위로 기록한다. 획득 그림 교체·중복 획득·재진입 규칙을 포함한다.
- 03 전투·완료 후04~17을 순차 진행한다.33·330~333·404~406은 실제 해금 경로가 확인된 뒤 진행하며, 목록 존재/씬 로드만으로 완료 처리하지 않는다.
- 맵/장식/캐릭터/효과/UI 깊이·가림, 효과 위치/방향/크기/시간, 대사/초상/글꼴/치환, 감정표현15종·씬 전환 정리를 확인한다. 원본 이미지 재사용과 원본 배치 재현을 구분한다.
- 실제 청음으로 지역BGM 전환/유지/복귀·시나리오 음악·마법/사망 효과음·중복/누락을 확인한다. AudioSource 존재만으로 청음 통과 처리하지 않는다.
- 직업별 MP 지속력·성장·전투 길이·장비/마법/고용·몬스터·XP/보상/가격을 함께 검토한다. 고효율58조합은 플레이 검토 후보이며 고정 상대 피해/AP만으로 하향하지 않는다. 기본 공격 훈련1회 사망도 하향 근거로 삼지 않는다.
- 반복 이동/전투/저장·씬 전환 중 입력·오브젝트/오디오/메모리 누적을 동일 조건 전후로 비교한다. 단일 시점 메모리 값만으로 누수 없음이라고 판단하지 않는다.

## 실행 결과 기록 양식과 종료 기준

| 항목 | 기록 |
|---|---|
| 식별 | 실행ID·커밋·Unity/플랫폼·EditMode/Play/빌드·계정/슬롯 별칭·격리 여부 |
| 사전 조건 | 선행 완료·맵/좌표·HP/MP·XP·돈·수량·장비·기술·영입/보상 상태 |
| 재현 | 실제 입력/공개API/fixture 사용을 구분한 순서 |
| 판정 | 통과 / 실패 / 미실행 / 근거 부족 |
| 기대/실제 | 수치·화면·상태 전이를 구체적으로 대조하고 근거 규칙 명시 |
| 증거 | 테스트 이름·오류·전체 스택·화면·Console·저장 전후 사본·해시·경로 |
| 수정/재검증 | 수정 없음 또는 개발 커밋, 같은 재현의 결과와 영향 회귀 |

- 실패 시 원래 상태를 보존한 뒤 별도 사본에서 재시도한다. 간헐 오류는 최초 실패와 성공한 재시도를 둘 다 기록한다.
- 진행 차단 시 선행 조건을 우회하지 않는다. 뒤 단계는 미실행으로 남기고 독립 검사를 계속한다.
- 자동 검사는 전체 XML과 개별 실패 JSON을 보존한다. 테스트 삭제/건너뜀으로 수치만 개선하지 않는다.
- TestRunner 자동 변경 설정은 실행 전 상태와 비교해 해당 변경만 복원한다. 게임 코드·사용자 변경을 일괄 되돌리지 않는다.
- 결과에는 완료 범위·남은 실패/미실행·실제 공유된 증거 경로를 쓴다. 로컬 저장 사본과 Git에 커밋/푸시된 자료를 구분하고 계정 비밀번호/인증 정보를 공유하지 않는다.
