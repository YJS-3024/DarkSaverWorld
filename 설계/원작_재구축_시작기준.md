# 원작 재현 새 시작 기준 (2026-10-31)

사용자의 요청에 따라 **이전 구현을 Assets에서 삭제하고 원본 자료를 바탕으로 다시 시작한다.** 현재 작업 위치는 `Assets/_Original`이다. 이전 `_Game` 코드/씬과 Resources·프리팹·ScriptableObject·타일 팔레트·임시 UI를 유지하며 수정하는 작업이 아니다.

## 이식에서 제외한 내용

기존 로그인·튜토리얼·마을·실내·전투·시나리오 실행기와 편집툴/테스트를 모두 제외했다. 임의 몬스터/NPC 배치, 지역명/연결, 자동 해금·보상·회복·거래, 전투 수식·AP·시간·합성 BGM·회원가입 디자인도 실행 설정으로 옮기지 않았다. 사용자 지정30000골드·AP최대20/초당2 등도 새 정책으로 재검토하기 전에는 자동 적용하지 않는다.

원문 자료는 미확정 의미를 보정하지 않은 참조다. 원본 스크립트에 명령이 있다는 사실과 서버 판정/화면 동작이 구현됐다는 사실을 구분한다. 비어 있는 편성이나 누락된 자료를 승리/보상으로 처리하지 않는다. PNG 전체 시트의 기본 Sprite 임포트 설정은 편집용이며 원작 프레임·깊이·타이밍 확정값이 아니다. 검정 투명화도 아직 적용하지 않는다.

## 이후 구현 기준

1. 시작·가입·로그인·서버 선택.
2. 캐릭터 생성·전체 튜토리얼.
3. 카오시아·실내 출입·시설.
4. 수련장.
5. 필드·시나리오.

각 단계는 원본 근거→작은 기능 구현→검증 순서로 진행한다. 클라이언트는 요청→로컬 서버 매니저→응답→표시로 구성한다. 원작 클라이언트의 확정 동작과 미확정 서버 정책/사용자 지정값을 분리한다. 원작 opcode가 확인되지 않은 로컬 계약을 원작 패킷으로 명명/기록하지 않는다.

기존 `Tools`의 생성기·검증기는 이전 `_Game` 경로와 타입에 의존한다. 새 Assets에 맞춰 검토·수정하기 전에는 실행하지 않는다. 과거 Unity/EditMode/통합 통과 수를 새 구현의 진행률/통과로 인용하지 않는다. 기존 분석 문서의 원본 증거와 과거 구현 이력도 구분한다.

## 검증 결과와 한계

- `python Tools/OriginalRestart/check_foundation.py`: 원본 자료2519출력의 해시·그림 픽셀·CSV·메타GUID2691개·구조·빌드 씬·실제 백업28662파일 검증 통과. 남은 기존 게임 C#0개, 시작 씬의 MonoBehaviour0개.
- 새 `OriginalFoundationSetup.cs`는 Unity6000.5.7f1 API 보조 컴파일 오류0·경고0. 이는 Unity 임포트/실행 결과가 아니다.
- Unity 배치 실행은 종료코드1. 라이선스 IPC 초기화 실패 및 Package Manager 로컬 IPC 연결 실패로 실제 임포트/메뉴 실행/씬 로드/Play는 미완료다. 게임 소스 컴파일 실패로 분류하지 않는다.
- 빌드 목록의 이전 씬 참조는 새 Start 하나로 교체했다. `기반 설정` 메뉴의 preloaded assets 초기화·ForceText 전환은 실제 Unity 실행이 필요하며 현재 실행 완료로 기록하지 않는다.
- Unity를 정상 실행할 수 있는 환경에서 `DarkSaver → 새 시작 → 기반 설정` 후 시작 씬의 카메라만 표시되는지, Missing Script/누락 참조/Console 오류 여부를 확인한다. 새 게임 기능은 아직 없어 로그인·전투 통과를 검사할 단계가 아니다.

## 백업과 근거

### 남은 Assets의 싱글판 잔존 재감사

- 새 기준 목록만 믿지 않고 별도 후기 파일 인벤토리와 실제 보존 Native ARC를 기준으로 재검사했다. 원본 바이트1238개, PNG/해독 텍스트1266개, CSV8개의 ATR 수치/행, 원본16맵610유닛의 SET/POS·직업·좌표·원문 행·추가값 및 배치 CSV 대응이 모두 일치했다.
- Assets에 이전 게임 실행 코드·보완 배치·임시 UI가 남아 있는 항목은 발견하지 않았다. 게임 런타임 C#0개, 에디터 기반 설정1개, 카메라/AudioListener만 있는 씬1개다. 소스 목록 밖 파일도 문서/어셈블리 정의/시작 씬/에디터 기반 코드로 한정됨을 검사했다.
- CSV category/itemCategory와 영문 별칭은 분석 편의 표기다. 카메라 배율7.5·Sprite PPU32는 새 Unity 작업용 기본값이며 원작 확정 게임 규칙이 아니다. 이 구분을 Data 설명과 검사 결과에 기록했다.
- Assets 밖의 이전 Tools·검증 이력·로컬 백업에는 과거 구현 자료가 남는다. 원작 증거와 혼용하거나 현재 Unity 실행 코드로 간주하지 않는다. 이번 재감사는 파일/정적 대조이며 Unity Play 실행을 추가한 것이 아니다.
- 결과: `Tools/OriginalRestart/foundation-check.json`의 `independentSourceAudit`. 게임 수치·원본 파일·배치 자료는 이번 재감사로 수정하지 않았다.

로컬 백업: `.local-backups/assets-restart-20261031T024437Z/working-files.tar`. `files-before.json`은 삭제 전 실제 파일별 SHA256이다. 커밋 전 수정/새 파일도 백업했으며 Git HEAD만 보관한 것이 아니다. 이 폴더는 `.gitignore`로 제외되어 다른 환경에 자동 공유되지 않는다.

작업/검사 결과: `Tools/OriginalRestart/reset-report.json`, `foundation-check.json`, `api-compile.json`, `unity-attempt.json`. 원본별 출처는 `Assets/_Original/SourceIndex.json`을 따른다. 삭제 스크립트는 이미 새 기준이 있는 상태에서 재실행을 거부한다.
