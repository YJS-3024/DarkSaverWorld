# 원본 자료

Native는 후기 설치본 인벤토리와 분석 files.json의 SHA256이 모두 일치한 데이터 파일이다. Unity에서 실행/오인식하지 않도록 원래 확장자 뒤에 .bytes를 붙였으며 내용은 변경하지 않았다. 실행 파일/DLL/설치기는 포함하지 않는다.

Decoded는 Native ARC에서 다시 추출한 스크립트/표를 엄격한 CP949로 해독하고 UTF-8로 인코딩한 참조 텍스트다. 명령·행·미확정 값을 보정하지 않는다. 해독할 수 없는 항목은 원본 ARC에 남겨두고 SourceIndex에 기록한다. 원본 실행 환경이나 서버 동작을 복원했다는 의미가 아니다.
