## 입력·실행 근거

1. 실제 Editor 임포트 뒤 `isCompiling=false`, `scriptCompilationFailed=false`, 지정 worktree 경로를 확인했다. API 컴파일만 실행한 결과가 아니다.
2. 새 경로의 `local-profile-v1.json`이 없는 것을 확인하고 Play를 시작했다. 직업 선택은 활성 Button의 정상 `onClick`, 이름은 실제 InputField에 입력한 뒤 정상 생성 버튼 콜백을 사용했다. **OS/물리 마우스·키보드 통과는 아니다.** 별도 서비스 생성·게임 진행 API 직접 호출은 하지 않았다.
3. 빈 이름 확인은 FirstCharacterCreation을 유지하고 이름 입력에 포커스를 돌려주는 정상 거부였다. 오류 모달을 기대하는 사례가 아니다.
4. 직업100, 이름 `Play1108`, `tutorialCompleted=false`로 저장됐다. 실제 Play에서 사부의 첫 인사와 방·캐릭터·이름 표시를 확인했다. 이후 대사 진행·F2·더블클릭·튜토리얼 완료 호출은 하지 않았다.
5. Editor의 정상 Play 종료 후 재진입했다. 저장 SHA와 캐릭터 투영값이 전후 동일하며, PrintWindow로 **해당 검증 Editor 창만** 캡처해 실제 Play 버튼과 `Play1108`·첫 대사 복원을 확인했다. 게임 그림을 새로 그리거나 합성·보정하지 않았다.
6. `01-*.json`~`21-*.json`은 실행 로그다. `reconnect-before.json`/`reconnect-after.json`에는 계정 인증 필드를 제외한 캐릭터 투영과 SHA만 남겼다. 계정 원본 파일은 커밋하지 않는다.

## 실행 제약과 근거 부족

- 검증용 프로세스·프로젝트 경로를 검증한 뒤 OS 포커스를 확보하려 했으나 두 번 모두 실패했다. 보호 조건이 클릭·키 전송을 거부했고 **실제 입력은 0회**다. 다른 창에 입력을 보내지 않았다. 물리 입력 경로를 우회하는 튜토리얼 서비스 호출도 하지 않았다. 전체 플레이를 이어가려면 직접 입력 가능한 환경이 필요하다.
- Play 재진입 후 릴레이는 `Unity not detected (no fresh discovery files found)`를 반환했고, 도메인 재로딩 대기 후 관찰 요청도 전체 시간 제한에 도달했다. 원격 읽기 명령이 나중에 실행될 수 있어 추가 요청을 반복하지 않았다. 재접속 화면은 별도 PrintWindow 캡처로 확인했다. 이는 게임 접속 실패 판정과 다르다.
- 일부 이미지 미리보기에서 변경되지 않은 배경·초상이 검게 보였다. **원본 PNG는 RGB이고 실제 배경·세 초상의 픽셀을 보유한다.** 선택 화면의 고정 배경 ROI는 최초 화면과 바이트 단위로 일치했다. 따라서 검은 미리보기를 제품 렌더링 결함이나 원본 PNG 누락으로 기록하지 않는다. `screenshot-pixel-diagnostic.json`, `screenshot-roi-diagnostic.json` 참조.
- 첫 임포트 로그에는 Unity AI 패키지의 `NoSubscription` 오류와 오래된 직렬화 버전 경고가 있다. 재접속 창 캡처 시 Console은 경고9·오류0을 표시했지만, 이를 세션 전체 Console 오류0이라고 확대하지 않는다. 전투·튜토리얼 후속 예외 없음도 주장하지 않는다.
- Reflection enum을 사용하는 상태 열거는 릴레이의 허용되지 않는 namespace 검사에서 거부됐다. 해당 열거를 실행하지 않고 공개 Entry/Tutorial 상태와 UI 문구만 읽었다. 이 도구 제한은 자동 승인 검토 거부나 게임 컴파일 실패가 아니다.

## 보존 및 후속 작업

- 기존 프로필 2개와 보호 배치·표 입력 12개의 SHA가 전후 동일하다. `preservation-before.json`, `preservation-after.json` 참조.
- 메인 tracked 변경은 실행 전부터 있던 `닥세_리소스/제목_없음.png` 삭제뿐이다. 이번 커밋에서 제외한다. 원본 코드·테스트·에셋 수정은 없다.
- 직접 조작은 검증용 `source.local - Start` Editor와 `Play1108` 프로필에서 이어가야 한다. 튜토리얼 입력을 정상 완료한 다음 P04~P20의 기능별·상황별 장면을 실행하고 각 화면을 추가해야 한다. 기존 메인 프로필이나 강제 해금으로 대체하지 않는다.
- 모든 시설·각 마법/기술·각 시나리오를 이번 8장으로 검증했다는 의미가 아니다. 남은 항목에 스크린샷이 없는 이유는 실제로 도달하지 않았기 때문이다.

## 준비 관찰

- 첫 Editor 실행은 장면 열기 인자를 포함했고 임포트 전 종료했다. 이유는 로그만으로 확인되지 않아 근거 부족이다.
- 장면 열기 인자를 제외한 별도 실행은 라이선스 확인·소스 컴파일·에셋 임포트를 진행했다.
- 기존 릴레이의 기본 대상은 메인 프로젝트였다. 읽기 전용 상태 확인으로 발견했고, 이후 검증 worktree 경로를 명시한 별도 도구 사본을 사용한다. 메인 프로젝트의 Play·저장 조작은 하지 않았다.
- 도구 명령 사본의 형식 오류와 선택적 System.Diagnostics 참조 오류는 진단 명령 컴파일 오류이며 게임 소스 컴파일 오류와 구분한다.
