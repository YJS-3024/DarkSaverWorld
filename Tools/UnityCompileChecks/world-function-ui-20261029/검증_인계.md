# 마을·필드 원작 기능키 UI (2026-10-29)

## 구현

GameCtl 전투 UI와 분리해 Saver1.2의 공유 월드 입력 분기와 Wlib 레이아웃을 사용했다. `WorldSessionHud.Awake`가 `NativeWorldWindows`를 붙이므로 기존 마을/필드 씬을 다시 저장하지 않는다. Screen Space Overlay Canvas를 쓰는 Unity UI이며 별도 UI 카메라가 필요 없다.

| 입력 | 연결 |
|---|---|
| F1 | 원본 scene19 도움말·help.txt·스크롤·닫기 |
| F2 | 원본 scene2 보유 캐릭터 요약·금액·메뉴 버튼·최소화·닫기·재열기 |
| F3 | 기존 scene6 자기정보 창. C키도 유지 |
| F4 | 기존 scene4 장비장착/소지품 창. I키도 유지 |
| F5 | 원본 scene3 대화창. scene3mm 확대·scene3m 최소화·닫기·로그 스크롤·입력/Enter 전송 |
| F8 | 원본 scene15 환경설정. 배경음악·효과음·전체대화·귓속말·메뉴보기·전체화면 |
| F9 | 원본 scene27 게임 종료 확인. 취소 시 입력 해제. 확인 시 Editor Play 종료/Player Quit |
| F12 | `/공간이동` 문자열을 Request_WorldText로 ServerManager에 전달 |

F6·7·10·11은 이 월드 처리기에 새 기능을 넣지 않았다. 이전 F5 임시 저장 단축키는 제거했다. 원작 전투 단축키·튜토리얼 처리기는 변경하지 않았다.

F2는 얼굴 초상이 아니라 기존 몸체의 row1/column1 그림을32×32 칸에 표시한다. 원본 `0x41C7E0`의 GetCharSurface와 source(32,32)-(64,64), 생성자의 기본 칸(38,86) 및 나머지 칸(41+38*열,140+50*행)을 대조했다. 이름/직업은(115,74)/(115,93), 금액 기준점은(141,301)이다. 미확인 가문은 임의 이름을 넣지 않는다. scene42/42m의 간소화 배경도 변환했지만 원작 계정 상태 필드의 의미가 미확정이므로 자동 선택하지 않는다.

버튼 기본/hover/눌림은 Wlib 원본3프레임을 사용한다. 창 위치 이동·스크롤·입력과 캐릭터 이동 클릭의 충돌을 분리했다. 채팅 입력 중 WASD/화살표 이동을 멈추고 I/C를 입력 문자로 취급한다. F키는 원본 CEdit의 상위 전달처럼 입력 포커스 중에도 처리한다. 입력 칸은 원본 공통 편집창 생성 `0x43A886..43A8F5`의(10,458)-(499,474)를 사용한다.

환경설정은 계정/게임 저장과 별도의 PlayerPrefs에 저장한다. 음악은 월드/시나리오 음악, 효과음은 월드 및 마법 효과에 반영한다. 전체대화·귓속말 수신 옵션은 Notify_WorldText의 채널을 필터링한다. 메뉴보기는 요약창 표시/숨김에 연결한다. 원작 옵션 비트에 연동된 모든 다른 네트워크 기능까지 복원했다는 뜻은 아니다.

## 명시적으로 남긴 경계

- 채팅·공간이동의 서버 판정/실제 다른 사용자 통신을 새로 만들지 않았다. 등록된 처리기 또는 기존 ServerManager 전달 경계를 사용하며, 없는 경우 처리 서버 미연결 메시지를 표시한다. 공간이동을 로컬 좌표 변경으로 대체하지 않는다. Request/Notify_WorldText는 로컬 UI 파사드이며 원작 opcode·wire packing이라고 주장하지 않는다.
- F2의 서버 부대 선택/체크 플래그, 다른 보유 캐릭터의 장비/자기정보 편집은 임의로 채우지 않는다. 해당 체크는 원본 버튼을 표시하되 서버 상태가 없어 비활성이다. 본인 자기정보·장비창은 기존 연결을 사용한다.
- 원작 설정의 현재 글꼴 선택 버튼은 그림을 표시하지만 대체 dark14-1/굴림/솔체 렌더러가 복원되지 않아 비활성이다. 이를 언어 변경 기능으로 해석하지 않는다.
- 일반 창의 최초 화면 위치는 이식 배치다. 원본 창 크기·내부 배경·버튼 좌표 및 위에 명시한 입력/몸체 칸과 구분한다. 후기 Saver.exe 동일 동작·전체 원작 재현을 확정하지 않는다.

- Unity 라이선스가 없어 실제 Editor 임포트/TestRunner/Play/OS 입력/청음은 미실행이다. 기존 검증 실패가 해결됐다고 판정하지 않는다.

## 다음 Unity 검증 순서

기존 실패 저장/계정 대신 격리 계정을 사용한다.

1. 임포트/Console 확인 후 `NativeWorldWindowsTests`10개 실행. 다른 원래 저장 파일은 수정하지 않는다.
2. 최초 로그인→튜토리얼에서는 월드 창이 나타나지 않는지, 카오시아 진입 후 F1/2/3/4/5/8/9가 위 표의 창을 여는지 실제 키보드 확인. C/I 호환 및 반복 키 닫기/재열기 확인.
3. F2 본체/돈/이름이 칸 안에 맞는지, 얼굴 초상이 들어가지 않는지, 최소화/복원과 원본 버튼→자기정보/장비/환경/도움말/종료 연결 확인. 비활성 부대 체크로 소유/편성 정보가 바뀌지 않아야 한다.
4. F3↔F4 전환·최소화·닫기와 장비 변경 기존 기능 확인. 창을 닫은 뒤 이동 잠금이 남지 않아야 한다.
5. F5 열기·확대/축소·최소화/복원·닫기, 원본 hover/눌림 이미지 확인. 입력 중 WASD/I/C로 캐릭터가 움직이거나 개인창이 열리면 실패. Enter 전송은 미연결 서버 거부/실제 등록 처리기의 결과로 구분. 보낸 말의 성공을 임의 표시하면 실패.
6. F8 각 체크·재시작 후 설정 유지, 배경음악/효과음 실제 청음, 대화 채널 알림 필터, 메뉴 표시, Player 전체화면 확인. 글꼴 전환은 미연결 상태로 기록.
7. F9 취소/ESC·확인, 확인 전에는 게임이 종료되지 않고 플레이어가 움직이지 않는지 확인. 다른 창의 잠금이 남거나 잘못 해제되지 않아야 한다.
8. F12 처리기 없음/거부/수락을 분리. 승인된 맵 응답 없이 위치/HP/돈이 변하면 실패. 서버 목적지 규칙을 이번 UI 통과로 세지 않는다.
9. 실제 출구로 필드 이동 후 같은 단축키 확인. 맵 이동·시나리오 연출·전투/훈련 전투에서는 새 월드 창이 숨겨지고 원래 전투 단축키에 간섭하지 않아야 한다. 창 위 클릭이 필드 이동/NPC/출입구를 발동하면 실패.
10. 원래 계정/실패 저장의 전후 해시 보존 확인. 전체화면/오디오 설정이 계정 HP/돈/튜토리얼/진행 저장을 바꾸면 실패.
