게임 화면 캡처 명령이 응답 대기 상태에 머물러, 프로세스와 프로젝트 경로를 확인한 뒤 검증용 Editor 창만 캡처했다. 기존 프로필 3개의 완료 기록은 모두 0개였다. 신규 프로필의 시작 상태는 기존 프로필과 분리했다.

직접 조작 방식은 사용자가 이전에 선택했다. `source.local - Start` 창에서 캐릭터 생성과 튜토리얼을 진행하고, 카오시아 도착 시 Play 상태와 캐릭터 이름을 확인한 뒤 마을 검증을 이어간다. 도달한 기능마다 실제 스크린샷과 실행 판정을 남긴다.
