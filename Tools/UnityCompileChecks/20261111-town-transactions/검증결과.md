# 테스트파이터 카오시아 거래 재검증

2026-11-11, Unity 6000.5.7f1, 소스 `26ef9011`. `DarkSaverWorld-Play-20261109`의 테스트파이터 저장으로 정상 재접속했다. 소모품점, 은행, 창고, 용병의 집, 신전에 걸어서 입장한 뒤 가판대 앞에서 직원에게 요청했다. 거래는 실제 Play의 게임 요청을 실행하고 응답을 화면에 표시하는 방식으로 검증했다.

| 기능 | 판정 | 실제 관찰 |
| --- | --- | --- |
| 소모품 구매 | 실패 | 실제 표시 상품의 구매 요청이 `RulesUnavailable`로 거절됨. [화면](screenshots/01-shop-buy.png) |
| 상점 판매 | 미실행 | 소지품 0개로 판매 대상 없음. [화면](screenshots/02-shop-sell.png) |
| 은행 입금 | 실패 | 1골드 입금 요청이 `RulesUnavailable`로 거절됨. [화면](screenshots/03-bank-deposit.png) |
| 은행 출금 | 실패 | 1골드 출금 요청이 `RulesUnavailable`로 거절됨. [화면](screenshots/04-bank-withdraw.png) |
| 창고 보관 | 미실행 | 소지품 0개로 보관 대상 없음. [화면](screenshots/05-warehouse-store.png) |
| 창고 회수 | 미실행 | 창고 물품 0개로 회수 대상 없음. [화면](screenshots/06-warehouse-retrieve.png) |
| 창고 확인 | 실패 | 창고 확인 요청이 `RulesUnavailable`로 거절됨. [화면](screenshots/07-warehouse-confirm.png) |
| 용병 고용 | 실패 | 실제 목록이 비어 있었다. 정적 목록의 파이터용 직업 200으로 보낸 요청은 `InvalidInput`으로 거절됨. 화면에서 선택 가능한 용병의 고용은 미실행. [화면](screenshots/08-mercenary-hire.png) |

지갑·은행 잔액은 실행 전후 미확인이었다. 현재 마을 데이터의 은행 수수료와 창고·고용 규칙도 미확정이다. 소지품·창고 물품·용병 수는 전후 각각 0개였다. 용병 후보는 성장 기술과 장비를 기준으로 계산되며, 이번 플레이 화면에는 후보가 없었다.

신전 UI는 성향 견적이 도착해야 창을 생성한다. 이번 실행에서는 요청 이벤트를 직접 관찰했지만 견적이 도착하지 않았다. 프로젝트의 `Assets` C#에서 해당 요청 이벤트를 구독해 견적을 반환하는 연결은 찾지 못했다. 성향 변경 완료는 미실행이다.

모든 시설에서 정상 퇴장한 뒤 카오시아 1000의 (11,9)로 복귀했고, 해당 좌표가 저장됐다. 요청별 결과와 자원 상태는 [실행 로그](transactions.log)에 있다.
