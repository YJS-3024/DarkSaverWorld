# 훈련장 종료 후 카오시아 입구 재접속

2026-10-28 KST. 사용자 확정: 훈련장 내부에서 게임을 종료하면 다음 접속은 카오시아 훈련장 입구 앞이다. 기존 설정의 FromTraining 위치8.5,21.5를 사용한다. 훈련장 중앙/내부 저장 위치로 재접속하지 않는다.

## 구현

- 훈련장 로딩/그리드 준비·서버 Ready 승인 후, 원래 마을을 해제하기 전에 `Request_SaveTrainingReturn`으로 입구 복귀 체크포인트를 저장한다. 저장 실패 시 서버의 미완료 진입을 취소하고 마을·원래 위치·입력을 보존한다. 따라서 종료 콜백만을 복귀 위치 기록의 유일한 기회로 삼지 않는다.
- 정상 종료/일시정지에서 로컬 훈련 방문을 감지하면 일반 SaveWorld 대신 훈련장 복귀 체크포인트를 갱신한다. 현재 방문 그리드에서 받은 HP/maxHP/MP/maxMP/생명 상태/경험치를 사용하며 캐릭터·인벤토리·기존 진행은 기존 세션에서 보존한다.
- 이 저장은 소유한 방문 그리드·선택 캐릭터의 실제 저장 경로·승인된 활성 훈련 세션을 확인한다. 기본 저장 경로로 임의 대체하지 않는다. 파일 쓰기가 실패하면 기존 원본/백업을 보존하는 NativeSaveStore 경로를 사용한다.
- 오래된101~107 내부 저장도 인증된 캐릭터 선택 응답을 준비할 때 위치만 입구로 보정한 사본을 반환한다. 읽기만으로 원본 파일을 덮어쓰지 않는다. 현재 마을/필드/시나리오 저장은 이 보정 대상이 아니다.
- HP0·사망 상태도 유지한다. 재접속 위치 변경을 무료 회복·부활·XP·금액·아이템 지급으로 취급하지 않는다. 훈련장 내부 전투 재개·몬스터 상태 복원은 추가하지 않았다.

강제 종료 때에는 마지막으로 성공한 체크포인트의 캐릭터 상태가 기준이다. 정상 종료/일시정지 시 최신 관찰 상태를 저장하는 경로와, 종료 콜백 없이도 입구를 복원할 수 있도록 입장 시 미리 저장하는 경로를 구분한다.

## 이번 실행

- Runtime/Editor/EditMode 보조 API 컴파일 오류0, Player Runtime API 컴파일 오류0. 기존 경고는 남는다.
- 연결된 프로덕션 소스 오프라인 통합5,744검사 통과. 신규64검사 포함이며 이전5,680개와 합산하지 않는다. JsonUtility 대체 어댑터를 사용하는 관리 코드 검사로 실제 Unity TestRunner/Play가 아니다.
- 신규64검사:101~107 위치 보정·HP/MP/XP/금액/아이템/완료 기록 보존·사망 무부활·입력 사본 분리·잘못된 좌표/맵 조합 거부·격리 계정 로그인/서버 선택/이전 내부 저장 선택·원본 파일 바이트 불변·입구 체크포인트 디스크 왕복·미래 형식 저장 덮어쓰기 거부.
- 실제 Unity에서 입장 선저장·중단/재접속·종료 콜백·저장 실패 입장 취소는 실행하지 않았다. 해당 NUnit 소스는 컴파일했으며 실제 실행 대기다.
- 사용자의 기존 실패 저장·계정·과거 검증 XML은 수정하지 않았다. 파일 쓰기 검사는 새 임시 디렉터리의 fixture만 사용했다.

## 실제 Unity 검증 순서

1. 별도 계정/저장으로 튜토리얼 완료 후 훈련장에 들어간다. 입장 직후 슬롯 파일의 위치가 Kaosia_Map/Town_Runtime·8.5,21.5인지 확인한다. 실제 화면은 훈련장 중앙에 있어야 한다.
2. 훈련장 안에서 Play 종료 후 같은 계정으로 로그인한다. 훈련장이 아니라 카오시아 훈련장 입구 앞8.5,21.5에서 등장해야 한다. 이동·카메라·물리·입구 자동 재진입이 없는지 확인한다.
3. 종료 전후 HP/MP/생명 상태/XP/골드/아이템/장비/완료 기록을 대조한다. 회복·부활·보상 재지급이 있으면 실패다. 정상 종료 콜백과 종료 콜백을 사용하지 않는 마지막 체크포인트 복원을 구분한다.
4. 예전 내부 저장의 격리 사본으로 로그인한다. 위치만 입구로 바뀌며 파일 읽기만으로 원본 사본이 덮어써지지 않는지 확인한다. 실제 과거 실패 저장 원본은 사용하지 않는다.
5. 격리 저장 실패 fixture에서 진입을 시도한다. 저장 실패 시 마을/입력/위치를 유지하고 서버 세션이 남지 않아야 한다. 정상 경로 복구 후 재진입 가능 여부도 확인한다.
6. 정상 도망 왕복과 일반 마을/필드 재접속이 이 정책 때문에 훈련장 입구로 바뀌지 않는지 확인한다.
