## 실패와 원인

1. **수련장 관리형 fixture 실패:** `Tools/OriginalWorldChecks/TrainingChecks.cs:64`, 기대 `WorldFailure.Busy`. 생산 `WorldService.cs:102`는 수련장 일반 이동을 `InvalidStage`로 거부한다. 원본 fixture는 “ordinary walk cannot bypass battle action requests”에서 중단됐고 이후 assertion은 미실행이다. 두 코드는 모두 거부이므로 실제 이동 우회가 허용됐다는 증거가 아니다. `failure-evidence/training-assertion.txt`에 오류·스택 보존. 테스트/생산 코드 미수정.
2. **튜토리얼 산출물 해시 실패:** `tutorial-assets.json`의 `분석/Saver_Late/waiting_tutorial_resources.json` 선언 해시와 Windows 사본 원시 바이트가 다르다. CRLF→LF 바이트만 가정했을 때 선언 해시와 일치한다. 원본 개행은 바꾸지 않았다. 관리형758은 이 실패 이전에 실제 완료했다.
3. **지도 애니메이션 산출물 감사 실패:** `map-animation-assets.json`이 선언한 `NativeWorldArt.asset` 해시가 현재 HEAD 자산과 다르다. CRLF-only가 아니다. 격리 사본 현재 바이트는 HEAD와 같고 이 자산의 worktree 변경도 없다. 이 선행 검사에서 중단되어 해당 네이티브 애니메이션 본체는 미실행이다.
4. **최종 통합 감사 실패:** 새 픽셀 검사 보고서의 해시를 참조하는 `native-battle-options-check.json`, `native-class-presentation-check.json` 두 보고서가 stale이다. 해시를 임의 갱신하지 않았다. 이후 통합 리소스/전체소스/GUID/정적근거 단계는 도달하지 못했다. 1차 통합에서는 nullable 보고서 의존 해시가 stale이었고 analyzer 재실행으로 해소한 후 최종 두 건이 남았다.
5. **Editor/패키지 오류:** 실제 Play 로그에 `UnityEditor.Search.SearchDatabase`의 ArgumentOutOfRangeException 2회와 Unity AI 패키지 NoSubscription/entitlement 오류가 있다. 게임 코드 스택으로 단정하지 않는다. 해당 로그 구간에 `error CS`, NullReferenceException, Crash!!!는 각각0회지만 Console 전체 무오류로 판정하지 않는다.

선언/실제 해시와 최종 stale 목록은 `static-audit-findings.json`, 핵심 오류·스택은 `failure-evidence/`에 있다. 네이티브 후기 Saver/GameCtl/UserUnit/DManage/NetGame 등은 저장소가 가리키는 Linux 추출 경로에 없으며 현재 사용 가능한 다른 버전 파일로 바꿔 통과시키지 않았다. 삭제된 `_Game` 자산을 참조하는 구형 입력 검사도 미실행이다.

## 실제 Unity 및 항목별 인게임 스크린샷
