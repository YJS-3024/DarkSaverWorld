## 자동화·환경 문제(제품 결함과 구분)

- 예전 드라이버가 비활성 암호 확인 버튼 및 삭제된10슬롯 화면을 기다려 시간 초과했다. 실행용 드라이버만 현재 흐름에 맞춰 재개했고 제품·테스트 소스는 수정하지 않았다.
- 나이트 장시간 명령의 응답 대기 종료 후 실제 명령이 늦게 완료됐다. 최종 로그와 실제301/커서18을 확인해 uGUI 완료로 기록했다.
- 이미 월드에 진입한 상태에서 활성 시작 메뉴를 찾던 API 시도는 조회 예외로 중단됐다. 변경 호출 전 예외이며 게임 실패로 분류하지 않았다. 매지션은 별도 새 계정 API 경로로 실행했다.
- 따라서 전체 실행 중 오류가 전혀 없었다고 주장하지 않는다. 마지막 Console0은 마지막 조회 범위에 한정된다.
