# 튜토리얼 UI 사용자 재현 4항목 수정

2026-10-28 KST. 원본 TUTORIAL.txt·저장 데이터·기존 검증 XML은 변경하지 않았다. 이번 화면 표시 변경은 사용자가 요청한 조정이며 새 원작 분석 확정값으로 기록하지 않는다.

## 변경

1. **행동 UI와 전투 상태 UI 겹침**: 행동 메뉴를 화면 안으로 제한하고 F2 상태창/축소창·F5 부대창과 겹치면 오른쪽으로 옮겨8px 간격을 둔다. 행동 아이콘의 별도 Canvas는 본문보다10 높은 순서를 쓰고 매 프레임 마지막 형제로 올린다. 앞뒤 순서만으로 가리는 문제와 물리적으로 같은 영역을 차지하는 문제를 함께 다룬다.
2. **아이콘 설명 중 회색 전환**: 원문의 CHARMENU 마스크가0이 되는 설명 구간에는 해당 배우의 마지막 강조 표시를 유지한다. 원문/진행 상태/마스크는 바꾸지 않는다. 클릭은 기존 mouseMenu·실제 마스크·용병 역할 조건을 그대로 적용한다. 용병의 이동/공격/휴식 외 아이콘은 계속 회색이다. 설명용 표시 캐시는 종료 시 비운다.
3. **본문 여백**: 대사 텍스트의 왼쪽/오른쪽/상단 간격과 승리조건 본문의 간격을 늘렸다. 도움말·설명 스크롤 본문에는 사방6px 여백을 두고 전체 높이에 위아래 여백을 포함해 마지막 줄을 잘라내지 않도록 했다. 고정 숫자 게이지·원본 이름칸의 좌표/그림까지 일괄 변경한 것은 아니다.
4. **범위 표시 시점**: 이동/공격 버튼을 실제 선택한 로컬 상태와 수신된 activeCommand가 모두 일치해야 범위를 그린다. 체크포인트 조회만으로 범위를 자동 선택하지 않는다. 명령이 바뀌거나 끝나면 이전 선택을 해제하며 메뉴가 열리거나 이동 중이면 범위를 숨긴다. 실제 선택 이후의 대사/안내 구간에는 범위가 유지된다. 마법도 명시적 시전 선택 조건을 유지한다.

## 이번 실행

- Runtime/Editor/EditMode 보조 API 컴파일 오류0, Player Runtime API 컴파일 오류0. 기존 경고는 남는다.
- 연결된 프로덕션 소스 오프라인644검사 통과. 신규 표시 규칙40검사를 포함하며 이전604개와 합산하지 않는다.
- 컴파일된 NUnit 어셈블리의 관리 검사 메서드1개를 직접 호출해 같은40검사를 통과했다. 별도40개로 합산하지 않으며 Unity TestRunner 실행이 아니다.
- 기존 회색 아이콘/범위 렌더러 검사의 기대를 사용자 지정 표시 조건에 맞췄다. 원문 마스크 불변과 선택 전 범위0도 검사한다.
- UI 본문 여백·전체 높이 및 실제 Canvas/범위 렌더러의 NUnit 소스는 컴파일했다. 실제 Unity 씬/글꼴 출력/입력/육안 검증은 미실행이다.

## 실제 Unity 재검증

격리 신규 계정으로 튜토리얼을 처음부터 실행한다. 기존 실패 저장은 보존한다.

1. F2 상태창과 F5 부대창을 연 상태에서 행동 메뉴를 연다. 확대·축소 상태 각각 메뉴가 상태창을 덮지 않고8px 이상 떨어져 있는지, 화면 가장자리에서도 아이콘이 잘리지 않는지 확인한다. 상태창 닫기/최소화와 행동 아이콘 클릭이 모두 동작해야 한다.
2. 이동·도구·마법·특수기·설정 등의 설명 중 강조→CHARMENU0→강조 구간을 녹화하거나 프레임별로 관찰한다. 강조 아이콘이 잠깐 회색으로 바뀌지 않아야 한다. 아직 입력을 허용하지 않은 단계에서는 밝게 보이더라도 클릭으로 넘어가면 안 된다. 용병의 지원하지 않는5개 행동은 회색이어야 한다.
3. 대사3줄·승리조건·도움말의 테두리 간격과 긴 설명의 마지막 줄까지 확인한다. 본문 여백 때문에 글자나 마지막 줄이 잘리면 실패다. 숫자 게이지/이름칸은 별도 고정 레이아웃이므로 본문 여백 검사와 구분한다.
4. 이동 버튼을 누르기 전에는 이동 범위가0이고, 누른 직후 표시돼야 한다. 안내 대사를 넘겨 이동을 완료하면 사라져야 한다. 공격도 버튼 전/후와 공격 완료를 동일하게 확인한다. 메뉴 재열기·우클릭 취소·다음 명령·재시작에 이전 범위가 남지 않아야 한다.
5. 마법·용병 지휘까지 진행해 버튼 선택·진행 대기 조건이 바뀌지 않았는지 확인하고, 완료 후 카오시아 진입과 Console 오류를 확인한다. 이번 작업에서 튜토리얼 전체 Play 완료를 통과 처리하지 않았다.
