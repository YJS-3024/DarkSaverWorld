# 마을·필드 기능키 구현 및 검증 인계 — 2026-10-29

기준 원본은 Saver1.2 실행 파일이다. 후기 실행 파일의 동일성이나 실제 원작 재생을 확인한 결과는 아니다. 이전 world-function-ui 기록 이후 변경을 기록하며 과거 로그를 대체하지 않는다.

| 키 | 반영 내용 |
|---|---|
| F1 | 전투 도움말과 같은 창(614×452, BattleWindows ID7)에 원본 월드 도움말 내용 표시 |
| F2 | 원본 요약창·최소화·선택 캐릭터·몸체 그림·금액. 선택을 F3/F4에 전달. 선택 플래그0x42와 슬롯 교환0x3B 요청 |
| F3 | 선택 캐릭터 자기정보와 원본 능력창. 수신한 원본 값·비용을 사용하며 0x86/82/84/81/88/89 요청 연결 |
| F4 | 선택 캐릭터 장비·28칸 소지품, 드래그 요청0x40. 해제는 FFFF,0,기존아이템. 장착 추가 원시값이 없으면 요청 차단 |
| F5 | 원본 대화창·최소화/확장·글꼴·입력. 로컬 ServerManager에 요청/검증/수신 알림/결과 처리 연결 |
| F8 | 음악·효과음·대화·귓속말·메뉴 설명·다음 실행 전체화면 설정. 귓속말 설정0x7D |
| F9 | 원본 종료 확인, Enter 확인/Escape 취소, 모달 중 다른 기능키 차단 |
| F12 | 원본 `/공간이동`을 F5와 같은0x7A 경로로 송신. 목적지·허용 조건은 서버 명령 처리기에 위임 |

## 원작 확인에 따른 보정

- F2 그림은 초상이 아니라 GetCharSurface의32×32 몸체 부분이다. 0x3B는 목적/출발 **슬롯**, 0x42는 레코드ID/플래그1·2다. 계정 저장의 주 캐릭터를 UI 선택으로 교체하지 않는다.
- F3 마법 선택 화살표의 원시 행동값은1/2다. 능력치 비용·전직 후보·장비 효과를 임의 계산하지 않는다. 전직 후보0x87은 기존 BindCharacterAdjustmentOptions 수신 어댑터에 카탈로그와 함께 공급해야 한다.
- F5 원본0x7A 구조는 opcode,mode,CP949 바이트길이,본문이며 NUL은 없다. 255바이트 초과·손상·변환 불가 문자를 거부한다. 일반 대화와 실제 접속한 자기 캐릭터의 귓속말을 로컬 처리하며 존재하지 않는 다른 유저를 만들지 않는다.
- F8 메뉴 보기는 F2 표시가 아니라 메뉴 설명 보드 표시다. 전체화면은 원작 초기화 경로에 따라 다음 Player 실행에 적용한다. 글꼴4종 중 dark14-1은 원본2592글리프를 변환했고 굴림·솔체는 설치 글꼴에 의존한다.
- F9는 F9 재입력으로 닫는 대신 원작처럼 Enter/Escape를 처리한다.

## 검증 결과

- Unity6000.5.7f1 참조 API 컴파일: Runtime/Editor/Tests/Player 오류0. Unity 실제 임포트나 TestRunner 실행이 아니다.
- 실제 컴파일한 코드의 직접 관리형 검사8개 통과. CP949/경계/로컬 대화/명령 위임/장비·선택·능력 요청/귓속말/수신 스냅샷 보존을 검사했다. Unity TestRunner 결과로 세지 않는다.
- 별도 기존 오프라인 통합5,832검사 통과. UI 실제 플레이 검사가 아니다.
- 원본12키 점프·공유 슬롯 정적 검사 통과, UI976개 정적 항목 통과, 대체 글꼴2592개 원본 마스크 통과.
- Unity 라이선스가 없어 실제 Editor 임포트·EditMode·Play·OS 입력·청음은 미실행. 새 Unity 통합4개 및 기존 월드UI10개는 컴파일만 확인했다.
- 기존 계정·실패 저장은 수정하지 않았다.

## 실제 Unity에서 확인할 순서

1. 로그인→튜토리얼 완료→마을/필드에서 F1/F2/F3/F4/F5/F8/F9/F12. 전투·튜토리얼 키와 혼동하지 않는다.
2. F1 전투 도움말 프레임과 월드 내용, F2 최소화·선택 몸체·F3/F4 선택 연동·창 겹침·드래그 확인.
3. 실제 원본 수신값을 공급한 F3 능력/마법/전직 후보와 F4 아이템을 검사한다. 선택 요청이 주 캐릭터 저장을 바꾸지 않는지 확인. 장비 승인·능력치 변경 서버 핸들러가 없으면 성공으로 세지 않는다.
4. F5 한글/영문 입력·Enter·255바이트·확장·최소화·스크롤·글꼴4종·일반 대화·자기 귓속말·미접속 대상 거부·0x7D 차단 확인.
5. F8 각 옵션과 재실행 유지 확인. 전체화면은 다음 Player 실행, 굴림/솔체는 설치 환경을 기록. 청음은 실제로 듣고 판정한다.
6. F9 취소/확인과 다른 창 입력 잠금 확인. 종료 확인은 별도 저장본에서 진행.
7. F12는0x7A 요청 및 서버 응답/거부 보존을 확인한다. 공간이동 목적지 규칙은 미확정으로 남기고 임의 텔레포트를 통과 처리하지 않는다.

## 남아 있는 서버 의존 범위

F5 로컬 대화·귓속말 설정은 처리된다. F2 플래그/순서 저장, F3 능력/마법/전직 승인, F4 장비 승인·효과, F12 공간이동 목적지·조건은 원본 서버의 권위 데이터/처리기가 필요하다. 이번 클라이언트 연결을 이 기능들의 원작 서버 구현 완료로 해석하지 않는다. 전체0x34 roster 디코더 대신 검증된 typed snapshot을 공급하는 경계다.
