# 닥세월드 공개 자료 조사

- 조사일: 2026-10-04
- 검색어: `닥세월드`, `닥세 월드`, `DarkSaverWorld`, `다크세이버 온라인 게임`, `다크세이버 자료 수집`
- 범위: 검색 엔진에서 접근 가능한 공개 웹 문서

이 폴더는 과거 온라인 게임 **다크세이버/닥세월드**를 현재 Unity 프로젝트에서 참고하기 위한 조사 자료입니다.

## 파일

- `조사_보고서.md`: 연혁, 게임 구조, 콘텐츠, 현재 프로젝트와의 연결점
- `출처_목록.csv`: URL 단위로 중복 제거한 출처와 신뢰도
- `리소스_매니페스트.csv`: 이후 자료를 추가할 때 사용할 중복 확인 목록
- `스크린샷_목록.csv`: 원작 여부, 원본 URL, 해상도, 해시 및 보존 상태
- `스크린샷_갤러리.md`: 저장된 화면 미리보기와 화면 구성 분석
- `스크린샷/`: 원본 출처에서 내려받은 조사용 이미지

## 중복 처리 원칙

동일한 정규화 URL은 한 번만 기록합니다. 이름이 달라도 내용과 출처가 같은 자료는 새로 복사하지 않고 기존 항목의 비고에 연결합니다. 이미지와 게임 원본 리소스는 권리 관계가 확인되지 않아 다운로드하지 않았으며, 출처 페이지 링크만 보존했습니다.

## 주의

팬 위키와 개인 블로그의 내용은 기억에 의존하거나 서로 모순될 수 있습니다. 특히 일부 개인 글의 “텍스트 기반 RPG” 설명은 다크세이버가 그래픽 온라인 RPG였다는 다른 기록과 맞지 않으므로 사실로 채택하지 않았습니다.
