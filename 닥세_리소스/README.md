# 닥세월드 원작 조사·분석 자료

공개 웹 조사(2026-10-04)와 설치본/코드 분석·싱글판 저작안(2026-10-24)을 보관한다.

## 읽는 순서

1. [조사 보고서의 현재 판독 기준](조사_보고서.md#current): 확인 범위·최신 정정·남은 항목.
2. [시나리오 연결](조사_보고서.md#scenario)과 [원작 편성](조사_보고서.md#actors): 원본에서 확보한 데이터.
3. [싱글판 보완안/규칙](조사_보고서.md#singleplayer): 원작에서 확인하지 못한 부분에 대한 신규 설계.

## 자료 위치

- `분석도구/`: 추출·원본 명령 검증·저작안/참조 검증 스크립트.
- `분석결과/`: CSV·JSON·asm·재구성 이미지. 같은 키를 포함해도 원문/조인/검증/저작안은 다른 자료다.
- `설치본_추출/`: 설치본과 아카이브 해제 자료.
- [스크린샷 갤러리](스크린샷_갤러리.md), `스크린샷_목록.csv`, `스크린샷/`: 출처와 보존 화면.
- `출처_목록.csv`: 정규화 URL·신뢰도. `리소스_매니페스트.csv`: 자료 중복 확인.
- `분석결과/분석_중복정리내역.csv`: 이번 설명/정본 정리의 변경 기록.

## 중복 처리

분석 설명은 `조사_보고서.md` 하나를 정본으로 사용한다. 중복 ` 2.md` 안내 파일과 내용이 합쳐진 중복 CSV는 제거했다. 근거/조건이 다른 검증 자료는 행 이름이나 주제만 같다고 합치지 않는다. 정규화 URL과 원본 파일 해시를 구분해 비교한다.

팬 위키·블로그의 기억 기반 설명과 설치본 근거를 구분한다. 실제 파일 보존 여부·출처는 각 목록을 따르며, 공개된 자료라는 사실만으로 원작 자산의 재사용 권리를 의미하지 않는다.

캐시·메타파일·원본과 동일한 변환본의 삭제 목록은 `분석결과/불필요파일_삭제목록.csv`에서 확인한다. 분석 도구가 직접 읽는 DEE UTF-8 변환본과 유일한 원본/근거는 유지한다.
