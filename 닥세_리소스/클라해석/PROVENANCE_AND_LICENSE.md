# 구성과 이용 안내

## 출처 기록

이 폴더의 Python 코드와 안내 문서는 이번 공개용 도구를 위해 새로 작성되었습니다. 기존 게임 구현 파일을 복사하지 않았으며 외부 코드 패키지를 포함하지 않습니다. Python 표준 라이브러리만 사용합니다. 테스트 입력은 테스트 코드가 만드는 단순 숫자·문자열·공개 규격의 합성 헤더입니다. 실제 클라이언트 파일이나 그 일부를 테스트 자료로 사용하지 않습니다.

포함: 범용 읽기 전용 구조 분석기, 합성 단위 테스트, 고정 목록 ZIP 생성기, 사용법과 권리 주의사항.

제외: 클라이언트·팩·실행파일·DLL·이미지·음원·대사·게임 소스·역분석 산출물·개별 게임 규격·계정·저장 파일·로그·패치·인증 우회·서버·자동전투/자동조작 AI·에디터.

공개 목록과 SHA-256은 ZIP 안의 release_manifest.json에 기록합니다. 이 해시는 공개 도구 자체의 해시이며 클라이언트 해시가 아닙니다. 목록 검사는 혼입 방지 수단일 뿐 법적 권리의 증명이 아닙니다.
