# 새 검증

기능을 다시 구현하면서 원문 근거와 실제 동작을 대조한다. 기존 테스트는 이전 구현에 의존하므로 자동 이식하거나 과거 통과 수를 현재 검증 결과로 표시하지 않는다. 구조/해시 검사는 Tools/OriginalRestart/check_foundation.py를 사용한다.

현재 진입 경로의 API/관리형 계약·파일 저장 검사는 Tools/OriginalEntryChecks/check_entry.py다. Unity 임포트/Play·OS 마우스/키보드·실제 그림 재생은 별도이며 현재 라이선스가 없어 실행하지 못했다. 실제 재검증 순서는 설계/원작_진입_UI_재구현.md를 따른다.
