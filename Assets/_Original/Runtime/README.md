# 새 런타임

기존 게임 로직은 남기지 않았다. Entry의 기본 흐름은 시작→별도 로컬 프로필→최초 지휘관 생성이다. 로그인·서버 선택 화면/요청/처리는 보존하지만 기본 경로에서 사용하지 않는다. Play 전에 EntrySceneRoot의 Use Login And Server Selection을 켜면 기존 계정 방식으로 돌아간다. 로컬 프로필은 OriginalLocalServer/local-profile-v1.json,기존 로그인 계정은 accounts-v1.json으로 분리한다.

Tutorial은 Saver.exe의1500 대기실 수업과 tutorial.arc의301 전투 수업을 순서대로 실행한다. 선행 수업 완료 전에는 전투 시작 요청을 거부한다. 미완료 재접속은1500부터 재시작하며,양쪽 수업을 끝낸 뒤 완료 상태만 저장한다. 기존 로컬 프로필이 있으면 그 캐릭터를 복원하며 로그인 계정을 자동 선택하거나 이전 저장을 이관하지 않는다.

화면/입력은 확인한 원작 근거를 따르고 LocalEntryPolicy/계정 파일 처리는 로컬 호스팅 정책으로 분리한다. 원작 wire opcode/서버 초기 수치·영구 실습 아이템 보상은 추측해 넣지 않는다. 원본 확인 범위·표시 환산·직접 검증은 설계/원작_튜토리얼_분석.md와 설계/테스트_검증_계획.md를 따른다.

World는 WorldEntryReady를 받아 카오시아21,21로 진입한다. 사용자 확인을 따른43×43 외부 지도와 후기 실내10종을 원본 타일·장식으로 표시하며,출입구·격자 보행·직원 클릭·시설 창을 LocalServerManager의 Request_/Notify_ 계약에 연결했다. 지도는 Start씬의 uGUI 실행기가 데이터로 구성한다. 별도 맵씬/Unity Tilemap을 생성한 것은 아니다. 외부 문과 실내의 연결 좌표·역할은 명시적인 로컬 설정이며 원작 서버의 좌표 복구로 취급하지 않는다.

무기·방어구·소모품·마법사의 집은 확인한 안내표의71품목,용병은 원본 병종/직업별 참조 목록을 사용한다. 장신구 재고는 보류다. 사용자 답변대로 초기 자금·은행/창고 수수료·부활 비용·고용 승인·매입가 등 미확정 운영값은 Data/World/KaosiaWorld.json의 rules에서 비활성 상태로 둔다. 미확인 금액은0으로 확정하지 않고 —로 표시하며 관련 확정 요청은 상태를 변경하지 않는다. 신전은 전용 원작 화면을 복구했다고 주장하지 않으며 원본 공통 금액 창을 연결했다.

수련장101은 가운데 입장·격자 이동·전투 상태창·옵션/도망 확인·마을 입구 복귀까지다. 원작 몬스터 편성/전투 서버 규칙은 넣지 않았고 미지원 행동은 비활성이다. 수련장 내부 종료 후에는 마을 수련장 앞을 복원한다. 일반 필드·시나리오·일반 전투·마을 전체 F키·월드 음향은 이번 범위에 포함되지 않는다. 관리형 상태 검사와 API 컴파일 결과는 Tools/OriginalWorldChecks/world-check.json을 보며 실제 Unity Play/물리 입력 통과와 구분한다.

편집기 메뉴 DarkSaver → 원작 도구 → 시나리오 편집툴은112개 원본 맵의 전투 배치 편집/연출 위치 참고·아군/상자/이벤트 좌표 표시를 지원한다. 코드는 Editor/Scenario에만 있으며 사용자 배치는 Editor/ScenarioLayouts에 저장한다. 원본 데이터와 게임 저장·런타임 스폰은 수정하지 않는다. 따라서 편집툴에서 수련장 몬스터를 추가/저장한 것과 실제 게임 등장/전투 연결은 별개다. 사용법과 원본 근거 경계는 Tools/ScenarioPlacementChecks/README.md를 따른다.

필드·시나리오 클라이언트 추가 후에는 NativeCampaignArt/CampaignCatalog가 원본 월드 맵29개와 시나리오97개를 제공한다. 마을/실내11개와 합쳐137개 지도 리소스를 지원한다. Runtime/Maps의 공유 MRC/GRS 해독기를 편집기와 게임에서 함께 쓰며 현재 맵의 바닥·장식·몸체를 분리해 표시한다. 대형 필드도 타일마다 버튼을 만들지 않고 하나의 격자 입력면을 사용한다. 미확정 좌표를 만들지 말라는 사용자 답변으로 신규 필드/시나리오 연결 설정은0개다. 따라서 카오시아에서 필드·시나리오로 걸어서 들어가는 새 출입구는 없다.

공유 해독기 적용 후 편집툴에도 월드/필드 필터를 추가했다. 현재 목록은 기존112+월드29=141개이며 원본1010 지도도 저장 변경 없이 확인할 수 있다. 편집기141지도와 런타임137리소스의 차이는 편집기에 수련장101~107·대련장201~207·튜토리얼301이 포함되고,런타임에는 마을/실내11종이 따로 포함되기 때문이다.

확인된16맵/610개 전투 개체는 원본 SET/POS 위치로 표시·점유 처리한다.97개 시나리오 중 도입 대본이 있는52개는 대사/배치/방향/이동/대기/지도 리소스 전환 상태를 처리한다. LOADSCENE은 서버 맵 이동과 구분하며21·24의25번,28~31의32번 연출 지도도 원문대로 표시한다. 효과/음악 호출은 Notify_ScenarioEffect로 전달하지만 전체 효과 패턴/음향 재생기는 이번에 연결하지 않았다. 실제 Windows 속도·Unity 화면 검증도 아니다.

Request_EnterMap은 근거 있는 연결/현재 위치/저장 성공이 필요하다. 원본 연결이 없으면 거부한다. Request_ClearScenario와 전투 결과/보상 자동 생성은 보류한다. 별도의 신뢰된 로컬 서버 어댑터가 Receive_ScenarioClear로 현재 맵/세션/중복 방지 알림을 제공할 때만 원본 종료 대본을 시작한다. 종료 대본의 FIRSTCLEAR/GETGENERAL 등 서버 의존 명령도 자동 판단/지급하지 않고 보류한다. intro/explore/outro/complete는 로컬 표시 복원 상태이며 전체 시나리오 처치 기록/능력치/보상 저장 구현을 뜻하지 않는다. 개발 결과는 Tools/OriginalWorldChecks/campaign-check.json,직접 검증은 설계/테스트_검증_계획.md 첫 절을 따른다.
